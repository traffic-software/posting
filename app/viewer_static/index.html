Browser profiles

Authenticate manually in Chrome, then reuse the selected profile in a task.

This desktop may show sensitive signed-in accounts. Do not share or record it. The viewer token grants privileged browser control. Enter website passwords and OTPs only inside Chrome, never in this panel. Agent mode is enforced read-only by the backend.

Use the separate viewer token, not your task API token.

Standalone browsing lasts up to 30 minutes by default. Closing Chrome saves this profile; it does not delete it. Tasks wait in the queue until you close standalone browsing. Live profile switching is not supported.

To select this profile for a task, include the displayed ID as browser_profile_id in your authenticated /run-task request, or use --browser-profile ID --prompt "…" in the submission helper. Task API authentication and write consent still apply.

Clipboard synchronization is disabled. Mouse and keyboard work only while the backend confirms your manual ownership.

Checking viewer session…

No screenshots are stored by this viewer. Logging out, session expiry, a prolonged disconnect, or manual timeout closes manual access. A task manual timeout fails the task rather than resuming unattended. Restart retains profiles but interrupts live sessions.
